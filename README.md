
# SpendSense – Personal Finance Voice Assistant

SpendSense is a Python-based personal finance assistant designed to help users manage and interact with their budget information through a simple desktop interface and voice interaction.

## Features

- Personal budget management
- SQLite database for storing budget information
- User-friendly desktop interface
- Speech recognition for voice-based interaction
- Text-to-speech responses
- Budget information management
- Date and time-based functionality

## Technologies Used

- Python
- Tkinter
- SQLite
- SpeechRecognition
- pyttsx3
- datetime

## How It Works

The application provides a desktop interface using Tkinter. Budget information is stored and managed using an SQLite database. Speech recognition allows users to interact through voice input, while pyttsx3 provides text-to-speech responses.
